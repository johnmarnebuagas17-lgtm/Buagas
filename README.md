Java Game Character 

An enhanced Java application built with Java Swing and Object-Oriented Programming (OOP) concepts.

Features
- Abstraction:`GameCharacter` abstract class with subclass implementations for `Warrior` and `Mage`.
- ADT (Abstract Data Type):Uses a list to store and manage character data.
- GUI & User Input:Java Swing interface allowing users to Add, Search, Update, Delete, and Perform Moves for characters.

How to Run

1. Open the project in Eclipse or any Java IDE.
2. Run `Main.java` as a **Java Application**.
3. Use the GUI window to interact with the characters!
